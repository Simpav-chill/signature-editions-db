# БД: signature editions (подписные издания)

# Проектирование сущностей

## Edition (издание)

| Ключ | Название атрибута | Описание                                               |
| ---- | ----------------- | ------------------------------------------------------ |
| ПК   | id                | Уникальный идентификатор                               |
|      | index             | Индекс издания                                         |
|      | type              | Вид издания, может быть только 'газета', либо 'журнал' |
|      | name              | Название издания                                       |
|      | price             | Стоимость подписки на издание на 1 месяц в рублях      |
## Recipient (получатель)

| Ключ | Название атрибута | Описание                                         |
| ---- | ----------------- | ------------------------------------------------ |
| ПК   | id                | Уникальный идентификатор                         |
|      | first_name        | Имя получателя                                   |
|      | last_name         | Фамилия получателя                               |
|      | patronymic        | Отчество получателя                              |
|      | settlement        | Населенный пункт, в котором проживает получатель |
|      | street            | Улица, на которой проживает получатель           |
|      | building          | Номер дома, в котором проживает получатель       |
|      | apartment         | Номер квартиры, в которой проживает получатель   |
|      | phone             | Номер телефона получателя                        |
## Subscription (подписка)

| Ключ | Название атрибута | Описание                 |
| ---- | ----------------- | ------------------------ |
| ПК   | id                | Уникальный идентификатор |
| ВК   | recipient_id      |                          |
| ВК   | edition_id        |                          |
|      | term              |                          |
|      | delivery_month    |                          |
|      | delivery_year     |                          |
# Таблица отношений

| Тип связи | Связываемые сущности   | Описание                                        |
| --------- | ---------------------- | ----------------------------------------------- |
| 1:М       | recipient-subscription | Один получатель может иметь много подписок      |
| 1:М       | edition-subscription   | Одно издание может предоставлять много подписок |

# Ограничения
- Подписка осуществляется одним получателем
- Подписка может быть осуществлена одним пользователем несколько раз на разные издания
- Издание предоставляет несколько подписок
- Несколько пользователей могут оформить подписку на одно и то же издание
- Подписки без получателя существовать не может
- Получатель не может существовать, если не осуществлял хотя бы одну подписку
- Подписки без издания быть не может
- Издание может существовать без подписки
# Реализация БД 
Реализация базы данных находится в директории init в корне проекта. Там лежит файл для создания БД с таблицами и индексами, а также файл для заполнения БД данными для тестирования запросов. Эти два файла выполняются автоматически при первом запуске `docker compose up -d`
