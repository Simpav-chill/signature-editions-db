# Описание репозитория

Этот репозиторий содержит выполнения заданий по курсу разработки, администрирования и зашиты баз данных, ПМ.04, который я прохожу в колледже. 

Он включает в себя проектирование концептуальной модели БД, построение ER-диаграммы отношений, реализацию этой БД в конкретной СУБД, а также обеспечение ее защиты и ее администрирование.

# Почему PostgreSQL

У нас на курсе используется MS SQL Server – она установлена на компьютеры в аудиториях, а также в документах практики инструкция для выполнения предоставлена именно к ней.

Но преподаватель разрешила использовать любую реляционную СУБД, так как они довольно похожи в методах разработки, защиты и администрации. Основной сложностью является только то, что прийдется искать инструкции в интернете, потому что некоторые части у разных СУБД отличаются, например, некоторые ключевые слова языка SQL. Но задания остаются те же.

Я решил не работать с MS SQL Server, а взять PostgreSQL, так как я уже немного знаком и работал с ней, и было бы неплохо прокачать этот навык. Также весомым аргументом в пользу данной СУБД было то, что на рынке это самая популярная СУБД, а значит на работе она будет встречаться часто, если не всегда.

# Почему СУБД и БД в docker контейнере

Данный подход я выбрал в связи с тем, что проще управлять данными, связанными с этой практикой. Поданобится удалить данные – я просто ввожу `docker compose down -v`, и данные удаляются.

Также позднее выяснилось, что часто приходится работать с коммандами docker, которых я ранее не знал, что прокачивает мой навык управления docker контейнерами и взаимодействия с ними. Также это прокачивает общее понимание того, как функционируют docker контейнеры.

# Почему я не использую PgAdmin

Я просто не захотел устанавливать программу. Мне было достаточно терминала и текстового редактора. И думаю, что довольно полезно уметь работать в терминале для более глубокого понимания работы того или иного инструмента.

# Как подключиться к БД

Пока что можно будет только подключиться к БД и проверить таблицы. Далее я сделаю так, чтобы можно было проверить SQL запросы, которые я составлял в ходе выполнения заданий из курса.

Прежде чем начать, нужно чтобы был установлен Docker. Для пользователей Windows дополнительно потребуется установить WSL с Linux дистрибутивом (при запуске Docker desktop он сам предложит установить это; если нет, тогда поищите в интернете гайд по установке).  

Убедитесь, что он запущен. 

Скопируйте данный репозиторий и выполните эту комманду в корне проекта:
``` bash
docker compose up -d
```

Чтобы подключиться и вводить запросы с коммандной строки, выполните:
``` bash
docker exec -it signature-editions psql -U postgres -d signature_editions
```

Все, теперь вы можете отправлять запросы СУБД и получать ответ. 

Для выхода из данного режима, введите прям там же:
``` bash
\q
```

Для остановки docker контейнера:
``` bash
docker compose stop
```
